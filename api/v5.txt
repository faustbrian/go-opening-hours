package openinghours // import "github.com/faustbrian/go-opening-hours/v5"

Package openinghours provides immutable recurring opening-hours schedules, dated
exceptions, explicit timezone evaluation, bounded search, and stable canonical
persistence. Start with NewSchedule and IsOpen for explicit instant queries.
LocalTime is a civil wall value, not an elapsed duration; ranges own their start
date and are start-inclusive/end-exclusive. A zero Schedule is closed without a
timezone, while a zero DayRule is inherited.

Constructed schedules and returned detached results support concurrent reads.
Constructors copy input collections; callers must not mutate them during a
call. Pointer decoding/scanning replaces caller storage and needs external
synchronization. The core owns no goroutines, clocks, network IO or database
lifecycle. Borrowed clock/observer capabilities execute synchronously.

Date and zone resolution use Calendar v2; timezone behavior depends on the
installed Go/IANA data, not a frozen rule snapshot. Canonical wire edition 1
is package-owned and carries provenance, not authentication. Optional adapters
introduce their declared client/module contracts and own no external service.

type Schedule struct {
	// Has unexported fields.
}
    Schedule is an immutable availability value. Its zero value is closed and
    carries no timezone; it never means always open. Constructed values may be
    shared for concurrent queries/algebra. Mutating a caller's *Schedule through
    Scan/Unmarshal is a distinct ownership boundary requiring synchronization.

func NewSchedule(config Config) (Schedule, error)
    NewSchedule validates and copies caller collections, nested rule slices
    and effective-date values without retaining mutable input containers.
    Nil weekly input is permitted. It admits an explicit installed location,
    at most 64 ranges per day and 4096 total direct/named exceptions; errors
    return a zero Schedule. Caller inputs must not be modified concurrently
    during construction.

func ParseJSON(data []byte) (Schedule, error)
    ParseJSON accepts one UTF-8 wire-edition 1 document of at most
    MaxJSONBytes, rejecting duplicate keys, unknown fields, excess nesting
    and invalid evaluated schedule fields. A zero-schedule envelope ignores
    metadata/effective/outside values; compositions reconstruct operand policies
    rather than outer wrapper fields. It borrows input only during the call.
    Accepted whitespace/key ordering need not be canonical bytes; CanonicalJSON
    normalizes them. Errors return zero without rendering input data.

func (s Schedule) CanonicalJSON() ([]byte, error)
    CanonicalJSON returns new stable compact wire-edition 1 JSON bytes, bounded
    by MaxJSONBytes after encoding. They include caller metadata/exception
    provenance, not automatically redacted content. Stability is representation
    identity, not frozen timezone rules, authentication or arbitrary algebraic
    equivalence.

func (s Schedule) Compare(other Schedule) (int, error)
    Compare returns -1, 0, or 1 according to the schedules' canonical byte
    ordering. It includes provenance and composition shape, like Equal.

func (s Schedule) EffectiveInstantRanges(start, end time.Time) ([]InstantRange, error)
    EffectiveInstantRanges returns clipped absolute availability within a
    bounded interval of at most 366 elapsed days. Ranges represent exactly
    IsOpen's civil point membership: folds may produce disjoint intervals and
    gaps contribute only existing wall times. At most 8192 collected fragments
    are admitted before normalization; errors discard partial results. Returned
    ranges are detached and sorted/merged.

func (s Schedule) EffectiveRanges(date Date) ([]DailyRange, error)
    EffectiveRanges returns normalized availability fragments for one civil
    date.

func (s Schedule) Equal(other Schedule) bool
    Equal reports canonical equality, including provenance and composition
    shape.

func (s Schedule) Hash() [sha256.Size]byte
    Hash returns the unkeyed SHA-256 of the canonical representation, including
    provenance/tree shape, or all-zero bytes when encoding exceeds limits.
    It is neither authentication nor proof of equivalent evaluated availability.

func (s Schedule) HumanSummary() (string, error)
    HumanSummary returns deterministic presentation text that is not a wire
    encoding and cannot be parsed by UnmarshalText. It excludes labels and
    exception provenance, reporting only the number of dated exceptions.

func (s Schedule) Intersection(other Schedule) (Schedule, error)
    Intersection returns a schedule open only when both operands are open.

func (s Schedule) IsOpen(instant time.Time) (Availability, error)
    IsOpen evaluates an absolute instant in the schedule's explicit timezone.

func (s Schedule) IsOpenLocal(date Date, localTime LocalTime, policy LocalResolutionPolicy) (Availability, error)
    IsOpenLocal resolves a civil date and wall-clock time under the explicit DST

    IsOpenNow evaluates an injected clock's current instant. Nil/typed-nil

func (s Schedule) MarshalJSON() ([]byte, error)

func (s Schedule) NextClosing(instant time.Time, horizon time.Duration) (Transition, error)
    NextClosing finds the first actual closing strictly after instant within
    NextTransition's bounded horizon.

func (s Schedule) NextOpening(instant time.Time, horizon time.Duration) (Transition, error)
    NextOpening finds the first actual opening strictly after instant within
    NextTransition's bounded horizon.

func (s Schedule) NextTransition(instant time.Time, horizon time.Duration) (Transition, error)
    NextTransition finds the first actual point-availability change strictly
    after instant. Candidates include civil endpoints in both fold occurrences
    and timezone-offset discontinuities. The positive horizon is at most 366
    elapsed days; exhaustion returns CodeSearchExhausted. Interval expansion and
    duration use the same civil point membership; see docs/timezones.md.

func (s Schedule) ObserveIsOpen(instant time.Time, elapsedClock ElapsedClock, observer Observer) (Availability, error)
    ObserveIsOpen runs IsOpen and reports bounded operational data. A nil clock
    disables elapsed measurement and reports a zero duration. Typed nil, panic
    or a nil measurement also means zero. Measurement covers IsOpen itself,
    excluding the separate RangeCount query and observer callback; collaborator
    work may block.

func (s Schedule) ObserveNextTransition(instant time.Time, horizon time.Duration, elapsedClock ElapsedClock, observer Observer) (Transition, error)
    ObserveNextTransition runs a bounded transition search and reports
    its outcome. A nil/panicking elapsed capability reports zero duration.
    SearchSteps estimates horizon-day cardinality rather than actual candidate
    visits; observer callback work is outside the measured query and remains
    synchronous.

func (s Schedule) OpenDuration(start, end time.Time) (time.Duration, error)
    OpenDuration sums elapsed duration of EffectiveInstantRanges' actual open
    intervals, not nominal wall-clock hours. It inherits that method's bounds
    and agrees with IsOpen's civil point membership across gaps and folds.

func (s Schedule) Overlay(other Schedule) (Schedule, error)
    Overlay returns a schedule where explicit right-hand rules override
    left-hand availability and inherited right-hand rules leave it unchanged.

func (s Schedule) PreviousTransition(instant time.Time, horizon time.Duration) (Transition, error)
    PreviousTransition finds the nearest actual point-availability change
    strictly before instant within a positive horizon of at most 366 elapsed
    days. Like NextTransition, it includes offset discontinuities and both
    fold occurrences. Closing explanations use the pre-boundary result; opening
    explanations use the post-boundary result.

func (s Schedule) Ranges(date Date) (DayResult, error)
    Ranges resolves the effective weekly rule for date. Missing and inherited
    weekly rules are closed because there is no lower-precedence source. This
    is not EffectiveRanges: dated exceptions, incoming spill, composition and
    effective-date bounds are not evaluated here. Returned ranges are copied.

func (s Schedule) ResolveLocal(date Date, localTime LocalTime, policy LocalResolutionPolicy) (ResolvedLocal, error)
    ResolveLocal converts a civil date and wall-clock time in the schedule zone.
    Gaps and folds are never resolved without the caller-selected policy. Exact
    occurrences succeed under every valid policy. PreferEarlier/PreferLater
    only select folds; only ShiftForward handles gaps and it rejects folds.
    A zero Schedule has no zone and fails with CodeInvalidTimezone.

func (s Schedule) Revision() string
    Revision returns the opaque bounded revision identifier.

func (s *Schedule) Scan(source any) error
    Scan implements sql.Scanner for JSON/JSONB bytes, strings, and NULL.
    NULL produces the fail-closed zero schedule. Non-nil input is bounded to
    MaxJSONBytes and decoded before assignment, leaving the previous receiver
    unchanged on failure. A nil receiver returns CodeInvalidState. Calls mutate
    caller storage and need external synchronization; no DB or connection
    lifecycle is owned.

func (s Schedule) SemanticallyEqual(other Schedule) bool
    SemanticallyEqual compares canonical wire representations after clearing
    schedule metadata recursively. Exception provenance, timezone, effective
    policies and composition shape remain significant; this is not a proof of
    arbitrary algebraic/point-set equivalence.

func (s Schedule) String() string
    String returns canonical JSON, including caller metadata/provenance,
    or a fixed error marker. It is not a secret-safe logging/redaction
    representation.

func (s Schedule) Subtract(other Schedule) (Schedule, error)
    Subtract returns a schedule open when s is open and other is closed.

func (s Schedule) Timezone() string
    Timezone returns the explicit IANA timezone identity, or empty for zero
    value.

func (s Schedule) Union(other Schedule) (Schedule, error)
    Union returns a schedule open whenever either operand is open.

func (s *Schedule) UnmarshalJSON(data []byte) error
    UnmarshalJSON decodes before replacing caller-owned storage; any error
    leaves the receiver unchanged. Nil returns CodeInvalidState and concurrent
    receiver mutation requires external synchronization.

func (s *Schedule) UnmarshalText(data []byte) error
    UnmarshalText implements encoding.TextUnmarshaler using the strict parser.

func (s Schedule) Value() (driver.Value, error)
    Value implements driver.Valuer using canonical JSON suitable for JSONB.
